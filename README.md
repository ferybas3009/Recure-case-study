# Recure

Técnico em Informática da FECAP.

Para conhecer mais sobre o projeto e acompanhar seu desenvolvimento:

https://www.instagram.com/recure.fisio/

## Sobre o projeto

A Recure é uma plataforma voltada para conectar pacientes e
fisioterapeutas, facilitando o acompanhamento da evolução do paciente
durante o processo de recuperação.

A plataforma utiliza tecnologias de detecção de movimento para auxiliar
na validação da execução dos exercícios realizados pelo paciente durante
o tratamento domiciliar, fornecendo informações que podem contribuir
para o acompanhamento realizado pelo fisioterapeuta.

## Segurança e privacidade

Por atuar na área da saúde, a Recure considera a segurança e a
confidencialidade das informações desde a concepção da plataforma.

A segurança é considerada na arquitetura do sistema e no tratamento dos
dados, buscando limitar o acesso às informações de acordo com a função
de cada usuário e reduzir a exposição de dados sensíveis.

O projeto também considera os princípios de privacidade e proteção de
dados aplicáveis a soluções de tecnologia em saúde, especialmente no
tratamento de informações relacionadas aos pacientes.
